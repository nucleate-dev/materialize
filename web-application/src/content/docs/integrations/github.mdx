# GitHub Integration

Connect your Nucleate projects to GitHub to enable version control, collaboration, and automated deployments.

## Prerequisites

Before using the GitHub integration, a team admin must connect GitHub to your team.

## Connecting GitHub

1. Go to **Dashboard → Team Settings → Integrations**
2. Click **Connect GitHub**
3. Authorize the Nucleate GitHub App
4. Select which repositories to grant access to

## Creating a Repository

Once GitHub is connected to your team:

1. Open your project in the Nucleate editor
2. Click the **Settings** icon in the toolbar
3. Go to the **GitHub** tab
4. Click **Create Repository**

This creates a new private repository in your connected GitHub account and pushes your project code.

## Syncing Changes

Changes you make in Nucleate are automatically synced to your GitHub repository. The AI assistant commits changes as you work.

## Repository Access

- Repositories are created as **private** by default
- Only team members with appropriate permissions can access the repository
- You can change visibility settings directly on GitHub

## Disconnecting GitHub

To disconnect GitHub from your team:

1. Go to **Dashboard → Team Settings → Integrations**
2. Click **Disconnect** next to GitHub

This removes the connection but does not delete repositories already created.

## Troubleshooting

### "GitHub not connected"
Ask a team admin to connect GitHub in Team Settings.

### Repository creation fails
- Ensure the GitHub App has permission to create repositories
- Check that you haven't reached GitHub's repository limit
- Verify the repository name is valid and not already taken
