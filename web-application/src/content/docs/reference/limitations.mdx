## Known limitations

### Development environment

| Limitation | Details | Workaround |
|------------|---------|------------|
| No native debugging | Can't attach native debugger | Use console.log, React DevTools |
| No custom native code | Managed workflow only | Use development builds |
| Limited file upload | 10MB per file | Compress large assets |
| No Git integration | Can't push/pull from IDE | Export and use local Git |

### Preview limitations

| Limitation | Details | Workaround |
|------------|---------|------------|
| Web preview only | No native preview in browser | Use Expo Go app |
| Some RN components | Not all work on web | Test on real devices |
| Camera/sensors | Limited in web preview | Test on physical device |

### Build limitations

| Limitation | Details | Workaround |
|------------|---------|------------|
| EAS builds only | No local builds | Use EAS for all builds |
| Queue times | Builds may be queued | Plan for build time |
| Limited customization | Managed workflow | Most apps don't need more |

## Providing feedback

### Feature requests

1. Visit [nucleate.dev/feedback](https://nucleate.dev/feedback)
2. Describe your use case
3. Explain why it matters

### Bug reports

1. Describe what happened
2. Steps to reproduce
3. Expected vs actual behavior
4. Screenshots if helpful

### Best feedback tips

| Do | Don't |
|----|-------|
| Describe the problem | Just say "it's broken" |
| Explain your use case | Prescribe the solution |
| Include examples | Be vague |

## Working within limitations

### When you hit a wall

1. **Check if there's a workaround** - Often there is
2. **Ask Claude** - It knows the platform well
3. **Check docs** - We document known issues
4. **Request the feature** - We prioritize by demand

### Maximizing what works

Nucleate is optimized for:
- ✅ Rapid prototyping
- ✅ AI-assisted development
- ✅ Expo/React Native apps
- ✅ Standard mobile features
- ✅ Easy deployment

Less optimized for:
- Complex native integrations
- Large team development
- Enterprise requirements
- Non-mobile platforms
