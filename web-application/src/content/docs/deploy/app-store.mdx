## What you'll accomplish

This guide covers:

- Preparing app metadata
- Creating screenshots
- Passing App Review

## Prerequisites

- App successfully on TestFlight
- All features tested and working

## Step-by-step

### 1. Prepare metadata

In App Store Connect, fill out:

- **App name** (30 characters max)
- **Subtitle** (30 characters)
- **Description** (4000 characters)
- **Keywords** (100 characters, comma-separated)
- **Support URL**
- **Privacy Policy URL**

### 2. Create screenshots

Required sizes:

- iPhone 6.7" (1290 x 2796)
- iPhone 6.5" (1284 x 2778)
- iPad 12.9" (2048 x 2732) - if supporting iPad

Tips:

- Show your app's best features
- Add marketing text overlays
- Use consistent styling

### 3. App Review checklist

Before submitting:

- [ ] App works without crashing
- [ ] All placeholder content removed
- [ ] Login works (provide test account)
- [ ] In-app purchases work
- [ ] Privacy policy accessible
- [ ] No broken links
- [ ] Accurate app description

### 4. Submit for review

1. Select your build in App Store Connect
2. Answer export compliance questions
3. Add review notes (test account if needed)
4. Click "Submit for Review"

## Rejection gotchas

### Common rejection reasons

| Reason              | How to fix                |
| ------------------- | ------------------------- |
| Crashes             | Fix bugs, test thoroughly |
| Placeholder content | Remove all "Lorem ipsum"  |
| Incomplete features | Remove or finish features |
| Login required      | Provide test credentials  |
| Privacy issues      | Add privacy policy        |

### Dealing with rejections

1. Read the rejection reason carefully
2. Fix the specific issue mentioned
3. Reply to the reviewer with what you fixed
4. Resubmit

## Checklist

- [ ] Metadata complete
- [ ] Screenshots uploaded
- [ ] Privacy policy added
- [ ] Test account provided
- [ ] Build selected
- [ ] Review notes added
- [ ] Submitted for review

## Common issues

**Review taking too long?** Average is 24-48 hours. Contact Apple if over a week.

**Rejected for vague reason?** Reply asking for specific details.
