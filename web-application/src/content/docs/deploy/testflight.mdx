## What you'll accomplish

By the end of this guide, you'll have:
- Apple Developer account set up
- EAS configured for iOS builds
- Your app on TestFlight

## Prerequisites

- Apple Developer account ($99/year)
- Expo account (free)

## Step-by-step

### 1. Apple Developer setup

1. Join the [Apple Developer Program](https://developer.apple.com/programs/)
2. Accept all agreements in App Store Connect
3. Create an App ID for your app

### 2. Configure app.json

```json
{
  "expo": {
    "name": "Your App",
    "slug": "your-app",
    "ios": {
      "bundleIdentifier": "com.yourcompany.yourapp",
      "buildNumber": "1"
    }
  }
}
```

### 3. Set up EAS

Ask Claude:
> "Help me configure eas.json for iOS production builds"

Or create manually:

```json
{
  "build": {
    "production": {
      "ios": {
        "distribution": "store"
      }
    }
  },
  "submit": {
    "production": {
      "ios": {
        "appleId": "your@email.com",
        "ascAppId": "1234567890"
      }
    }
  }
}
```

### 4. Build for iOS

```bash
eas build --platform ios --profile production
```

### 5. Submit to TestFlight

```bash
eas submit --platform ios
```

## Bundle IDs

Your bundle identifier must be unique worldwide.

Format: `com.companyname.appname`

Example: `com.nucleate.myawesomeapp`

## Common build failures

| Error | Solution |
|-------|----------|
| Invalid provisioning profile | Re-run with `--clear-credentials` |
| Bundle ID in use | Choose a different bundle identifier |
| Missing signing certificate | Let EAS manage certificates |

## Checklist

- [ ] Apple Developer account active
- [ ] Bundle identifier set
- [ ] EAS configured
- [ ] Build completed
- [ ] Submitted to TestFlight
- [ ] Added test users

## Common issues

**Build failing?** Check that your Apple Developer account is in good standing.

**Can't submit?** Make sure all App Store Connect agreements are accepted.
