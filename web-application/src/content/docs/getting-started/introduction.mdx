## What you'll accomplish

By the end of this guide, you'll have:

- Created your first Nucleate project
- Previewed your app in real-time
- Understood the file structure and mental model

## Step-by-step

### 1. Create a project

Start by visiting [nucleate.dev](https://nucleate.dev) and clicking "New Project". Choose from our starter templates or start from scratch.

### 2. Preview your app

Once your project is created, you'll see the live preview on the right side of the screen. Any changes you make will appear instantly.

### 3. Understand the file structure

Your Nucleate project follows standard Expo/React Native conventions:

```
app/
├── (tabs)/           # Tab-based navigation
├── _layout.tsx       # Root layout
└── index.tsx         # Home screen
components/           # Reusable components
constants/            # Theme and config
```

### 4. Share & fork model

Every Nucleate project can be shared via URL. Others can fork your project to create their own version.

## How Nucleate differs from local dev

- **No setup required** - Everything runs in the cloud
- **AI-assisted development** - Chat with Claude to build features
- **Instant preview** - See changes immediately without bundling
- **One-click deploy** - Ship to TestFlight or Play Store

## Checklist

- [ ] Created a new project

## Common issues

**Preview not loading?** Try refreshing the page or checking your network connection.

**Files not syncing?** Wait a moment - file sync happens automatically.
