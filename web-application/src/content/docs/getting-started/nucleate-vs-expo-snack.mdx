- When to use Nucleate vs Expo Snack

## Step-by-step comparison

### When to use Expo Snack

Expo Snack is great for:

- Quick code examples and demos
- Learning React Native basics
- Sharing small snippets
- Reproducing bugs for Stack Overflow

### When to use Nucleate

Nucleate shines when you need:

- **Full app development** - Not just snippets
- **AI-assisted coding** - Claude helps you build
- **File-based routing** - Expo Router out of the box
- **Proper theming** - Dark/light mode support
- **Third-party integrations** - Supabase, payments, etc.
- **Deployment** - Actually ship to app stores

## Why Snack breaks down

| Feature               | Expo Snack  | Nucleate                        |
| --------------------- | ----------- | ------------------------------- |
| Navigation            | Basic       | Expo Router with full support   |
| Theming               | Manual      | Built-in theme system           |
| AI Help               | None        | Claude-powered assistance       |
| Deployments           | Export only | Direct to TestFlight/Play Store |
| File Management       | Limited     | Full file system                |
| Environment Variables | None        | Secure secrets management       |
